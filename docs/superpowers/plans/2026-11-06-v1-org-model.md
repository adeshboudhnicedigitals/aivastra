# v1.0 Org Model (Branches + Staff) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every merchant branches and up to N staff logins per branch (N set per merchant, default 2, editable only by AiVastra admin), with a merchant-side API for the merchant admin and an AiVastra admin screen that can alter any of it.

**Architecture:** Build step 1 of `docs/architecture/v1-hld.md`. Two new tables (`merchant_branches`, `merchant_staff`) and three new `merchants` columns. A new `requireMerchantMember` decorator beside `requireMerchant` resolves the caller to `{ merchantId, role, branchId }` — the merchant owner (`merchants.user_id`) is implicitly `admin`, a `merchant_staff` row makes a user `staff`. Staff are ordinary `users` rows (email + password, `emailVerified: true`) so `/v1/auth/login` works for them unchanged.

**Tech Stack:** Fastify 5 + `fastify-type-provider-zod`, Drizzle ORM / Postgres 16, Zod in `@aivastra/types`, Vitest integration harness, Vite + React admin SPA.

## Global Constraints

- pnpm only; ESM only; no `console.log` (use the request/app logger).
- Every `/admin/*` route uses `requirePermission(...)` from `apps/api/src/modules/admin/guard.ts`. Reuse the existing `merchants.read` / `merchants.write` keys — no new permission migration.
- Every mutation writes `recordAudit(tx, …)` inside the same transaction, after the write, before commit.
- Staff limit is checked in the **same transaction** as the staff insert, with the branch row locked `FOR UPDATE`.
- Never `DELETE` branches or staff — deactivate with `is_active = false`.
- Migrations are generated and applied **locally only** (`pnpm db:generate`, `pnpm db:migrate`). Never against production.
- Do not commit unless the user asks (repo rule in `CLAUDE.md` overrides the per-task commit steps below — treat "Commit" steps as "stage and stop" unless told otherwise).
- Admin-web dropdowns use `SearchableSelect`, never a raw `<select>`.
- Integration tests need `pnpm docker:up` running. Run one file with
  `cd apps/api && npx vitest run --config vitest.integration.config.ts <pattern>`.

**Deviation from the HLD (record it in Task 6):** HLD §4.1 says the owner gets an `admin` row in `merchant_staff`. This plan instead treats `merchants.user_id` as the implicit admin, so `merchant_staff` holds only staff and no merchant-creation path (`POST /admin/merchants`, Android onboarding, WordPress connect) needs changing. `merchant_staff.role` is therefore omitted.

```ts
// deactivated — because sessions, devices and jobs will reference it.
export const merchantBranches = pgTable(
  'merchant_branches',
  {
    id: uuid('id').primaryKey().defaultRandom(),
    merchantId: uuid('merchant_id')
      .notNull()
      .references(() => merchants.id, { onDelete: 'cascade' }),
    name: text('name').notNull(),
    city: text('city'),
    address: text('address'),
    isActive: boolean('is_active').notNull().default(true),
    createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
    updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
  },
  (t) => [index('merchant_branches_merchant_idx').on(t.merchantId)],
);

// A staff login. The credentials live on `users` (same pattern as merchants and
// admin_users); this row is the membership. The merchant OWNER (merchants.user_id)
// is the merchant admin and has no row here. user_id is unique: one user is staff
// of at most one merchant.
export const merchantStaff = pgTable(
  'merchant_staff',
  {
    id: uuid('id').primaryKey().defaultRandom(),
    merchantId: uuid('merchant_id')
      .notNull()
      .references(() => merchants.id, { onDelete: 'cascade' }),
    branchId: uuid('branch_id')
      .notNull()
      .references(() => merchantBranches.id),
    userId: uuid('user_id')
      .notNull()
      .unique()
      .references(() => users.id, { onDelete: 'cascade' }),
    isActive: boolean('is_active').notNull().default(true),
    createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
    updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
  },
  (t) => [index('merchant_staff_branch_idx').on(t.branchId, t.isActive)],
);
```

```ts
export const portalAuthPlugin = fp(async (app) => {
  const secret = new TextEncoder().encode(app.env.JWT_SECRET);

  // Authorizes off the same access token the catalogues-web user session uses
  // (aud-less, kind:'access', sub = users.id) — a merchant is a user with a
  // merchants profile attached, so there is no separate merchant login/token.
  async function userIdFromBearer(req: FastifyRequest): Promise<string> {
    const h = req.headers.authorization;
    const token = h?.startsWith('Bearer ') ? h.slice(7) : undefined;
    if (!token) throw new AppError('UNAUTH', 401, 'missing bearer');
    try {
      const payload = await verifyAccess(secret, token);
      if ((payload as Record<string, unknown>).kind !== 'access') {
        throw new AppError('UNAUTH', 401, 'invalid token');
      }
      return String(payload.sub);
    } catch (err) {
      if (err instanceof AppError) throw err;
      throw new AppError('UNAUTH', 401, 'invalid token');
    }
  }

  app.decorate('requireMerchant', async (req, _reply) => {
    const userId = await userIdFromBearer(req);
    const [client] = await app.db
      .select({ id: schema.merchants.id, isActive: schema.merchants.isActive })
      .from(schema.merchants)
      .where(eq(schema.merchants.userId, userId))
      .limit(1);
    if (!client) throw new AppError('FORBIDDEN', 403, 'not a merchant account');
    if (!client.isActive) throw new AppError('FORBIDDEN', 403, 'merchant account inactive');

    req.merchantClientId = client.id;
  });

  // v1.0 org model: the merchant OWNER is the merchant admin (no merchant_staff
  // row); anyone else must hold an active merchant_staff row in an active branch.
  // Owner-only routes keep using requireMerchant above, unchanged.
  app.decorate('requireMerchantMember', async (req, _reply) => {
    const userId = await userIdFromBearer(req);

    const [owner] = await app.db
      .select({ id: schema.merchants.id, isActive: schema.merchants.isActive })
      .from(schema.merchants)
      .where(eq(schema.merchants.userId, userId))
      .limit(1);
    if (owner) {
      if (!owner.isActive) throw new AppError('FORBIDDEN', 403, 'merchant account inactive');
      req.merchantMember = { merchantId: owner.id, userId, role: 'admin', branchId: null, staffId: null };
      return;
    }

    const [staff] = await app.db
      .select({
        staffId: schema.merchantStaff.id,
        merchantId: schema.merchantStaff.merchantId,
        branchId: schema.merchantStaff.branchId,
        staffActive: schema.merchantStaff.isActive,
        branchActive: schema.merchantBranches.isActive,
        merchantActive: schema.merchants.isActive,
      })
      .from(schema.merchantStaff)
      .innerJoin(schema.merchantBranches, eq(schema.merchantBranches.id, schema.merchantStaff.branchId))
      .innerJoin(schema.merchants, eq(schema.merchants.id, schema.merchantStaff.merchantId))
      .where(eq(schema.merchantStaff.userId, userId))
      .limit(1);
    if (!staff) throw new AppError('FORBIDDEN', 403, 'not a merchant member');
    if (!staff.merchantActive) throw new AppError('FORBIDDEN', 403, 'merchant account inactive');
    if (!staff.staffActive) throw new AppError('FORBIDDEN', 403, 'staff account inactive');
    if (!staff.branchActive) throw new AppError('FORBIDDEN', 403, 'branch inactive');
    req.merchantMember = {
      merchantId: staff.merchantId,
      userId,
      role: 'staff',
      branchId: staff.branchId,
      staffId: staff.staffId,
    };
  });

  app.decorate('requireMerchantAdmin', async (req, reply) => {
    await app.requireMerchantMember(req, reply);
    if (req.merchantMember?.role !== 'admin') {
      throw new AppError('FORBIDDEN', 403, 'merchant admin required');
    }
  });
});

export interface MerchantMember {
  merchantId: string;
  userId: string;
  role: 'admin' | 'staff';
  branchId: string | null;
  staffId: string | null;
}

declare module 'fastify' {
  interface FastifyRequest {
    merchantClientId?: string;
    merchantMember?: MerchantMember;
  }
  interface FastifyInstance {
    requireMerchant: (req: FastifyRequest, reply: FastifyReply) => Promise<void>;
    requireMerchantMember: (req: FastifyRequest, reply: FastifyReply) => Promise<void>;
    requireMerchantAdmin: (req: FastifyRequest, reply: FastifyReply) => Promise<void>;
  }
}
```

```ts
/**
 * Locks the branch row and refuses when it already holds staffLimitPerBranch
 * ACTIVE staff. Must run inside the transaction that then inserts/activates the
 * staff row: the FOR UPDATE lock is what serializes two concurrent creates so
 * both cannot pass the count.
 */
export async function assertBranchHasStaffCapacity(
  tx: DbTransaction,
  merchantId: string,
  branchId: string,
): Promise<void> {
  const [branch] = await tx
    .select({ id: schema.merchantBranches.id, isActive: schema.merchantBranches.isActive })
    .from(schema.merchantBranches)
    .where(and(eq(schema.merchantBranches.id, branchId), eq(schema.merchantBranches.merchantId, merchantId)))
    .for('update');
  if (!branch) throw new AppError('NOT_FOUND', 404, 'branch not found');
  if (!branch.isActive) throw new AppError('VALIDATION', 400, 'branch is inactive');

  const [merchant] = await tx
    .select({ limit: schema.merchants.staffLimitPerBranch })
    .from(schema.merchants)
    .where(eq(schema.merchants.id, merchantId));
  const [{ n } = { n: 0 }] = await tx
    .select({ n: count() })
    .from(schema.merchantStaff)
    .where(and(eq(schema.merchantStaff.branchId, branchId), eq(schema.merchantStaff.isActive, true)));
  if (n >= (merchant?.limit ?? 0)) {
    throw new AppError('STAFF_LIMIT_REACHED', 409, 'this branch already has its maximum number of staff');
  }
}

/**
 * Shared by the merchant-side and AiVastra-admin staff PATCH routes. Activating a
 * staff member, or moving an active one to another branch, consumes a seat in the
 * target branch, so it goes through assertBranchHasStaffCapacity.
 */
export async function updateStaff(
  app: FastifyInstance,
  req: Parameters<typeof recordAudit>[1]['request'],
  staffId: string,
  body: MerchantStaffUpdateBody,
  ctx: { merchantId: string; actor: { userId: string; role: string } },
) {
  return app.db.transaction(async (tx) => {
    const [existing] = await tx
      .select()
      .from(schema.merchantStaff)
      .where(and(eq(schema.merchantStaff.id, staffId), eq(schema.merchantStaff.merchantId, ctx.merchantId)))
      .for('update');
    if (!existing) throw new AppError('NOT_FOUND', 404, 'staff not found');

    const targetBranch = body.branchId ?? existing.branchId;
    const willBeActive = body.isActive ?? existing.isActive;
    const consumesSeat = willBeActive && (!existing.isActive || targetBranch !== existing.branchId);
    if (consumesSeat) await assertBranchHasStaffCapacity(tx, ctx.merchantId, targetBranch);

    const [row] = await tx
      .update(schema.merchantStaff)
      .set({ branchId: targetBranch, isActive: willBeActive, updatedAt: new Date() })
      .where(eq(schema.merchantStaff.id, staffId))
      .returning();
    await recordAudit(tx, {
      actor: ctx.actor,
      action: 'merchant_staff.update',
      resourceType: 'merchant_staff',
      resourceId: staffId,
      before: { branchId: existing.branchId, isActive: existing.isActive },
      after: { branchId: row!.branchId, isActive: row!.isActive },
      request: req,
    });
    return row!;
  });
}
```

```ts
import { schema } from '@aivastra/db';
import { AdminMerchantBranchUpdateBody, AdminMerchantStaffUpdateBody } from '@aivastra/types';
import { and, asc, eq } from 'drizzle-orm';
import type { FastifyInstance } from 'fastify';
import type { z } from 'zod';
import { AppError } from '../../lib/errors.js';
import { updateStaff } from '../merchant/org.routes.js';
import { recordAudit } from './audit.js';
import { requirePermission } from './guard.js';

// AiVastra admin can alter any merchant org setting (v1-hld.md §3.4). Creation
// stays with the merchant admin in Merchant Web; admin corrects and overrides.
export async function adminMerchantOrgRoutes(app: FastifyInstance) {
  app.get(
    '/admin/merchants/:id/org',
    { preHandler: requirePermission('merchants.read') },
    async (req) => {
      const { id } = req.params as { id: string };
      const [merchant] = await app.db
        .select({
          staffLimitPerBranch: schema.merchants.staffLimitPerBranch,
          deviceQuotaPerMonth: schema.merchants.deviceQuotaPerMonth,
          storeUrl: schema.merchants.storeUrl,
        })
        .from(schema.merchants)
        .where(eq(schema.merchants.id, id));
      if (!merchant) throw new AppError('NOT_FOUND', 404, 'Merchant not found');

      const branches = await app.db
        .select()
        .from(schema.merchantBranches)
        .where(eq(schema.merchantBranches.merchantId, id))
        .orderBy(asc(schema.merchantBranches.createdAt));
      const staff = await app.db
        .select({
          id: schema.merchantStaff.id,
          branchId: schema.merchantStaff.branchId,
          userId: schema.merchantStaff.userId,
          email: schema.users.email,
          displayName: schema.users.displayName,
          isActive: schema.merchantStaff.isActive,
          createdAt: schema.merchantStaff.createdAt,
        })
        .from(schema.merchantStaff)
        .innerJoin(schema.users, eq(schema.users.id, schema.merchantStaff.userId))
        .where(eq(schema.merchantStaff.merchantId, id))
        .orderBy(asc(schema.merchantStaff.createdAt));

      return {
        ...merchant,
        branches: branches.map((b) => ({ ...b, staff: staff.filter((s) => s.branchId === b.id) })),
      };
    },
  );

  app.patch(
    '/admin/merchants/:id/branches/:branchId',
    { preHandler: requirePermission('merchants.write'), schema: { body: AdminMerchantBranchUpdateBody } },
    async (req) => {
      const { id, branchId } = req.params as { id: string; branchId: string };
      const body = req.body as z.infer<typeof AdminMerchantBranchUpdateBody>;
      return app.db.transaction(async (tx) => {
        const [existing] = await tx
          .select()
          .from(schema.merchantBranches)
          .where(and(eq(schema.merchantBranches.id, branchId), eq(schema.merchantBranches.merchantId, id)))
          .for('update');
        if (!existing) throw new AppError('NOT_FOUND', 404, 'branch not found');
        const [row] = await tx
          .update(schema.merchantBranches)
          .set({ ...body, updatedAt: new Date() })
          .where(eq(schema.merchantBranches.id, branchId))
          .returning();
        await recordAudit(tx, {
          actor: { userId: req.userId, role: req.adminRole! },
          action: 'merchant_branch.update',
          resourceType: 'merchant_branch',
          resourceId: branchId,
          before: existing,
          after: row,
          request: req,
        });
        return row!;
      });
    },
  );

  app.patch(
    '/admin/merchants/:id/staff/:staffId',
    { preHandler: requirePermission('merchants.write'), schema: { body: AdminMerchantStaffUpdateBody } },
    async (req) => {
      const { id, staffId } = req.params as { id: string; staffId: string };
      return updateStaff(app, req, staffId, req.body as z.infer<typeof AdminMerchantStaffUpdateBody>, {
        merchantId: id,
        actor: { userId: req.userId, role: req.adminRole! },
      });
    },
  );
}
```

```tsx
import { useCallback, useEffect, useState } from 'react';
import { apiErrorMessage, apiFetch } from '../lib/data';
import type { MerchantOrg } from '../types';
import { SearchableSelect } from './SearchableSelect';

// v1.0 org model: AiVastra admin view of a merchant's branches and staff. Creation
// happens in Merchant Web; here admin can deactivate, re-activate and move staff.
export function MerchantOrgPanel({
  merchantId,
  onToast,
}: {
  merchantId: string;
  onToast: (t: { kind?: 'error'; title: string }) => void;
}) {
  const [org, setOrg] = useState<MerchantOrg | null>(null);
  const [busy, setBusy] = useState<string | null>(null);

  const load = useCallback(async () => {
    try {
      setOrg(await apiFetch<MerchantOrg>(`/admin/merchants/${merchantId}/org`));
    } catch (err) {
      onToast({ kind: 'error', title: apiErrorMessage(err, 'Failed to load branches') });
    }
  }, [merchantId, onToast]);

  useEffect(() => {
    void load();
  }, [load]);

  async function patch(path: string, body: Record<string, unknown>, key: string, ok: string) {
    setBusy(key);
    try {
      await apiFetch(path, { method: 'PATCH', body: JSON.stringify(body) });
      onToast({ title: ok });
      await load();
    } catch (err) {
      onToast({ kind: 'error', title: apiErrorMessage(err, 'Update failed') });
    } finally {
      setBusy(null);
    }
  }

  if (!org) return null;
  const branchOptions = org.branches.map((b) => ({ id: b.id, label: b.name }));

  return (
    <div className="card">
      <h3>
        Branches & staff <span className="badge">limit {org.staffLimitPerBranch} per branch</span>
      </h3>
      {org.branches.length === 0 && <p>No branches yet — the merchant creates them in Merchant Web.</p>}
      {org.branches.map((b) => (
        <div key={b.id} className="card">
          <div>
            <strong>{b.name}</strong> {b.city && `· ${b.city}`}{' '}
            <span className="badge">{b.isActive ? 'active' : 'inactive'}</span>{' '}
            <button
              type="button"
              className="btn btn-sm"
              disabled={busy === b.id}
              onClick={() =>
                patch(
                  `/admin/merchants/${merchantId}/branches/${b.id}`,
                  { isActive: !b.isActive },
                  b.id,
                  b.isActive ? 'Branch deactivated' : 'Branch activated',
                )
              }
            >
              {b.isActive ? 'Deactivate' : 'Activate'}
            </button>
          </div>
          <ul>
            {b.staff.map((s) => (
              <li key={s.id}>
                {s.displayName ?? s.email} ({s.email}){' '}
                <span className="badge">{s.isActive ? 'active' : 'inactive'}</span>{' '}
                <button
                  type="button"
                  className="btn btn-sm"
                  disabled={busy === s.id}
                  onClick={() =>
                    patch(
                      `/admin/merchants/${merchantId}/staff/${s.id}`,
                      { isActive: !s.isActive },
                      s.id,
                      s.isActive ? 'Staff deactivated' : 'Staff activated',
                    )
                  }
                >
                  {s.isActive ? 'Deactivate' : 'Activate'}
                </button>{' '}
                <SearchableSelect
                  options={branchOptions}
                  value={s.branchId}
                  onChange={(branchId: string) =>
                    branchId !== s.branchId &&
                    patch(`/admin/merchants/${merchantId}/staff/${s.id}`, { branchId }, s.id, 'Staff moved')
                  }
                />
              </li>
            ))}
            {b.staff.length === 0 && <li>No staff</li>}
          </ul>
        </div>
      ))}
    </div>
  );
}
```
