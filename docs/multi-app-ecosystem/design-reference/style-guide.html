Kiosk ergonomics — not phone density
Primary tap targets in this reference are 56–64px (icon buttons, primary CTA height), not the 44–48px phone floor — sized for a stand-back, imprecise tap at arm's length. Body text holds at 16px minimum against photographic backgrounds using a scrim, not a lighter/smaller treatment, to stay legible under bright, variable store lighting.
