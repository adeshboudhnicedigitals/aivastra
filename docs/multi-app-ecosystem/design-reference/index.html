Each mockup was built from the actual current XML (activity_home_dresses_for.xml, activity_vastra_try_on.xml, activity_vastra_try_on_result.xml, dialog_select_vastra_gender.xml) — same elements, same arrangement, same content. This is a kiosk tablet app, not a desktop/web app — there are no hover states or nav-link browsing in the real app; this index page is just a local file-browsing convenience for reviewing the 5 references, not itself a screen.
Poppins loads here via Google Fonts CDN for preview convenience only — the app already bundles the matching TTF weights locally (regular/medium/bold/extrabold/black), no new font asset is needed.
